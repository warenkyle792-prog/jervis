JERVIS
v1.0.5 · desktop app

Your computer, done for you.

Say “Hey Jervis” and ask for music, videos, timers or documents — or have it use your mouse and keyboard for you. The AI runs locally on your machine: no account, no API key, no cloud.

After you download

Run the installerWindows: SmartScreen → More info → Run anyway. macOS: Privacy & Security → Open Anyway.
Let it set upFirst start downloads Ollama, llama3.2 and an offline speech model (~2.3–3.6 GB). Non-AI features work meanwhile.
Say “Hey Jervis”Ask it to open apps, write a document, play something, or control the screen.
Tune itGear icon → microphone, voice, wake phrase, computer control, privacy and start-at-login.

Good to know

  • App size: ~190 MB download, ~460 MB installed. Windows 10/11 or macOS on Apple silicon only.
  • Everything stays on your computer: %APPDATA%\Jarvis on Windows, ~/Library/Application Support/Jarvis on macOS.
  • With 16 GB of RAM it can also see pictures and your screen (optional 3 GB vision model).
  • Installers come straight from the upstream GitHub Releases — nothing is redistributed here.
  • The full source is already in this repo at jervis-app-source/ (~34 MB, 594 files). Refresh it with ./get-source.sh.
  • One-command installers live in this repo: install-windows.ps1 and install-mac.sh (they verify SHA256 before launching).
On Linux? The desktop app has no Linux build. The browser-based Jervis assistant is still in web-assistant/ — run python3 -m jarvis.web from that folder and open http://127.0.0.1:8765.
